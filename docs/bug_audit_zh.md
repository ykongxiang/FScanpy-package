# FScanpy 预测与绘图检查记录

本次检查针对官方 PyTorch 包，从 master 的 `5d79296` 开始。模型结构、模型权重、33/399 bp 输入长度及原有密码子窗口对齐方式保持不变。以下问题均有可复现输入，并加入回归检查。

| 问题 | 原行为及影响 | 本次处理 |
|---|---|---|
| 短序列双侧补 N | `ATG` 提取 33 bp 时变成左侧 23 个 N、右侧 7 个 N，扫描位置被移动 | 根据原坐标分别补齐两侧，恢复左 16 / 右 14 |
| 奇数长度差裁剪 | 34 bp 裁至 33 bp 仍返回 34；CNN 的 400 bp 输入无法 reshape，随后返回全零 | 保证裁剪结果精确达到目标长度 |
| 短输入特征维度 | `ATG` 生成 196 维，模型需要 836 维 | 统一预处理并补齐到训练维度 |
| 失败被当作零概率 | 模型或特征处理报错被捕获，随后返回零概率；区域接口还会再次吞掉异常 | 抛出包含模型及位置/行号的异常，不伪造预测 |
| 输入元数据覆盖预测 | `data` 中已有 `Ensemble_Probability` 等字段会覆盖刚计算的分数 | 仅复制不与预测字段冲突的元数据 |
| 显示阈值与推理门控冲突 | 显示阈值设为 0.02，短模型分数 0.05 的位置仍未运行长模型 | 绘图接口门控设为 `min(0.1, short_threshold)`，常用默认行为保留 |
| U 及模糊碱基的处理不一致 | 短模型将 U 当作 T，PyTorch 长模型将 U 当作 N；两者对模糊字符的处理也不同 | 统一 U→T、非 ATGCN 字符→N |
| 热图重叠覆盖 | 相邻弱信号覆盖强信号；柱状图 0.95 对应热图变成 0.3 | 重叠区域保留最大分数，与输入行顺序无关 |
| PDF 保存路径 | 字符串替换会把目录名里的 `.png` 也改成 `.pdf` | 仅替换文件后缀，支持 Path 和大写 PNG |
| FScanR 肽段去重字段 | 肽段去重使用 DNA 坐标，可能误删不同肽段位点或保留重复肽段位点 | 按原 R 实现使用 `Pep_FS_start` / `Pep_FS_end` |
| FScanR 到窗口的坐标转换 | BLASTX 的 1-based 坐标直接作为 0-based 使用；反向互补后没有转换位置 | 先转换坐标及方向，再沿用密码子对齐提取；新增 `coordinate_base=0` 选项 |
| 文档中的方法缺失 | README 展示 `predictor.extract_features()` 和 `get_model_info()`，实际调用产生 AttributeError | 补齐特征提取及模型类型、有效输入长度查询 |
| 遗留预测助手返回空表 | `SequenceFeatureExtractor.predict_region_batch()` 调用不存在的 `predict_region()`，随后吞掉异常 | 作为弃用兼容入口委托给公开区域预测接口，不再假装预测成功 |

去重修复后，包内 BLASTX 示例返回 11 个位点，旧结果为 16；这是按正确肽段坐标去重的结果变化，相关测试同步检查这 11 个位点。正反链坐标修复也会改变受影响区域的窗口及分数，属于实质性修正。独立提供的标准 399 bp 区域预测和新版教程完整 CDS 预测另作回归核对，不把这些变化归因于模型权重更新。

绘图已经进入包的公开接口：`plot_prediction_results()` 用于已有结果，`plot_prediction_regions()` 用于局部并排比较；现有绘图入口增加可选参考标线和面板比例。两者无需重复推理，并保留两个热图和黑色柱状图布局。逐位扫描对重复窗口复用预测，输出坐标和行数保留。

本次保留用户中文 notebook 的全部 Markdown 描述，仅更新运行代码与输出。新增使用说明见[中文绘图 API 指南](plotting_zh.md)。本地 TensorFlow 开发实现具有另一套模型和特征流程，本 PR 不将其替换或混入官方 PyTorch 实现；本次结果不等于完整审计了该开发实现。

参考：[FScanR 原始 R 实现](https://github.com/seanchen607/FScanR/blob/master/R/FScanR.R)、[NCBI BLASTX 坐标说明](https://blast.ncbi.nlm.nih.gov/Blast.cgi?LINK_LOC=blasthome&PAGE_TYPE=BlastSearch&PROGRAM=blastx)。

验证结果：源码及安装后的 wheel 均通过 55 项测试。官方 Demo、新版中英文预测教程及可复用绘图示例均在仓库外、无相邻数据目录的环境中完整执行成功。五条完整教程序列和 703 行逐位扫描结果与修复前逐项比较，概率最大绝对差均为 0。教程的 Markdown 描述与作者版本逐单元格核对保持不变；旧版参考文件逐字节保留。详见 [notebook 与安装包验证记录](tutorial_validation_zh.md)。

本机 705 nt 序列逐位扫描的两次测量中位耗时约从 2.63 秒降至 0.95 秒；最终验证期间有其他任务同时运行，另一次测量为 1.18 秒。此处只说明重复密码子窗口缓存的效果，不作为全基因组性能基准。扫描行数仍为 703，概率逐项一致。
